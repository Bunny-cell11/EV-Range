# EV Range Estimator with Agentic Workflow

## Overview
This project predicts EV range using ML and introduces agentic behavior through automated decision-making.

## Agentic Features
- Automated training pipeline
- Performance evaluation agent
- Decision-making logic (retrain if error exceeds threshold)
- Modular architecture

## Workflow
1. Train model
2. Evaluate performance
3. Agent decides:
   - Accept model OR
   - Retrain automatically
4. Predict EV range

## Run
pip install -r requirements.txt
python main.py
